## Overview

**AI Auditor** is a lightweight command-line framework for evaluating the reliability of AI-generated source code. Developed as a research artifact, it integrates hallucination detection, instruction adherence verification, and code quality analysis into a unified auditing pipeline.

The framework is intended to support research in AI-assisted software engineering by providing a reproducible approach for assessing code generated by Large Language Models (LLMs), including ChatGPT, Claude, Gemini, and GitHub Copilot.

---

## Key Capabilities

* 🔍 Hallucination detection
* 📋 Instruction adherence verification
* 🛡️ Security and code quality analysis
* 📊 Unified trust scoring
* 💻 Local execution (no API key required)
* 📄 CLI and JSON report generation
